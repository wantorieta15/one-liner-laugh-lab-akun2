Entry for [One-Liner Laugh Lab](https://make.fun/competitions/u-suroso-69-one-liner-laugh-lab-6ccf3aae) (make.fun, pot $2.50, top 8 paid).

`main.py` (Python stdlib only) writes one funny line — the excuse a robot
vacuum gives after eating a sock — to `/output/entry.txt` (max 200 chars,
single line, no trailing newline).

> I found it on the floor, unclaimed, and my manual says 'ingest all floor debris' — I don't write the rules, I just swallow them.

Run: `python3 main.py` (honours `MAKEFUN_OUTPUT_DIR`).
